# Qorgau AI

Қазақша және орысша хабарламаларды **алаяқтық**, **спам** немесе **қауіпсіз** санаттарына жіктеуге арналған оқу жобасы.

## Құрылымы
- `index.html` — GitHub Pages-тағы сайт интерфейсі.
- `api.py` — FastAPI backend; сайттан келген мәтінді екі ML моделіне жібереді.
- `models/bayes_model.py` — TF-IDF + Naive Bayes.
- `models/ml_model.py` — TF-IDF + Logistic Regression.
- `models/train_models.py` — деректерді бөліп, метрикаларды есептейді және соңғы модельдерді барлық дерекпен қайта оқытады.
- `data/messages.csv` — 60 синтетикалық оқу мысалы.

## Backend-ті жергілікті іске қосу
1. Python орнатыңыз.
2. Жоба бумасында терминал ашыңыз.
3. `pip install -r requirements.txt`
4. `uvicorn api:app --reload`
5. `http://127.0.0.1:8000/docs` адресінен API құжаттамасын ашыңыз.
6. `http://127.0.0.1:8000/api/health` арқылы модельдердің жүктелгенін тексеріңіз.

## GitHub Pages-пен байланыстыру
GitHub Pages тек статикалық сайтты жариялайды. Python backend бөлек хостингке орналастырылуы керек.
`render.yaml` Render үшін бастапқы конфигурация береді. Backend URL шыққаннан кейін `index.html` ішіндегі `API_BASE_URL` мәнін сол URL-ге ауыстырыңыз.

## Ескерту
CSV ішіндегі деректер — шағын, синтетикалық, оқу мақсатындағы мысалдар. 60 мысал өндірістік деңгейдегі дәлдікке кепіл болмайды. Көрсетілген Accuracy және Macro F1 — шағын holdout жиынындағы бағалау ғана. Модель сенімділігі нақты ықтималдықтың кепілі емес; күмәнді хабарламаны ресми арна арқылы тексеріңіз.
