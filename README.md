# Qorgau AI

Қазақша және орысша SMS/хабарламаларды **алаяқтық**, **спам** немесе **қауіпсіз** санаттарына жіктеуге арналған оқу жобасының прототипі.

## Іске қосу
1. Python орнатыңыз.
2. Терминалда жоба бумасына кіріңіз.
3. `pip install -r requirements.txt`
4. `streamlit run app.py`

## Команда міндеттері
- Айзере: агент логикасы және интеграция (`agent/message_agent.py`)
- Ажар: Naive Bayes (`models/bayes_model.py`)
- Кәусар: TF-IDF + Logistic Regression (`models/ml_model.py`)
- Ұлжан: Streamlit интерфейсі, тестілеу және құжаттама (`app.py`, `tests/`, `README.md`)

## Ескерту
`data/messages.csv` ішіндегі деректер — тек шағын синтетикалық демонстрациялық мысалдар. Бұл модель нақты алаяқтықты сенімді анықтайды дегенді білдірмейді. Жоба оқу мақсатында жасалған; нәтижені әрдайым адам тексеруі керек.
